# 案例：88 秒固态电池科普视频

用本 skill 完整跑通的第一条片子。横版 1920×1080，成片 88.47 秒，16 句解说、477 字。

## 每一步的真实产出

| 步骤 | 做了什么 | 产出 |
|---|---|---|
| 1 定题核事实 | 选题"固态电池年年跳票"；逐项核数字（通稿 + 独立来源）。查到"全固态手机至今 0 台上市"成为全片角度 | 事实清单 |
| 2 脚本 | 按 5–6 字/秒定长：90 秒 ≈ 480 字。一句一个信息点，五幕骨架 | `script.md`（16 句定稿） |
| 3 配音 | Gemini 3.8 Flash TTS（Charon 声线）全文一次生成，原始音频 95.2 秒；切句得到时间表，句间停顿统一压到 0.45 秒 → 成片轨 88.47 秒 | `sentences.json`、`timing.json` |
| 4 画面 | anatomy 生成三张解剖图（电芯结构 / 液态电芯 / 固态电芯），用 `scripts/record.mjs` 录屏取动画 | 三段网页录屏 |
| 5 素材 | Mixkit 实拍（充电站、插枪特写、雪原航拍）+ 同站授权配乐，音乐垫人声下约一成音量 | 素材文件 |
| 6 合成 | 按时间表拼装；切换落在标点处（`timing.json` 里的 `s01_cuts` / `s02_cut` 就是第一句的两个分句切点）；字幕整句上屏 + 深色衬条 | 成片 |
| 7 自检 | 16 句逐句抽帧核对画面↔解说↔字幕；全片完整听一遍查毛刺；峰值 −0.53 dB | 交付 |

## `timing.json` 怎么读

- `onsets`：每句在成片轨上的起始秒数。字幕和镜头切换全按它走。
- `track_dur`：压缩停顿后的配音总长（88.47 秒）。
- `s01_cuts`：第一句内部两个分句停顿的位置，开头实拍在这里切镜。

切句由 `scripts/slice_sentences.py` 完成：两遍预测对齐这张表时 15 个句界 13 个在 0.5 秒内，其余会在输出的 `warnings` 里点名候选停顿，人工复核即可。
