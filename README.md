# explainer-video-pipeline-skill

一个人 + AI 工具链做一条 60–120 秒科普解说视频的全流程 skill：核事实、写脚本、AI 配音、会动的解剖图、实拍素材、按标点合成、交片自检，每一步都有定版规则和验收标准。

首个完整案例：**88 秒固态电池科普视频**（实证材料在 [`examples/solid-state-battery/`](examples/solid-state-battery/)）。

## 这是什么

这是一个给 AI 助手用的 **skill（说明书 + 工具包）**，不是独立软件。它由三部分组成：

- **`SKILL.md`** —— 全流程说明书：七步的顺序、参数、规则、避坑和自检门禁。这是核心资产。
- **`scripts/`** —— 五个自研小工具，补齐没有现成工具的环节（都以案例的量产素材回归验证过）：
  - `tts_gemini.py` —— Gemini TTS 一次调用生成整段配音（请求格式与量产一致，带配额错误处理）
  - `slice_sentences.py` —— 把配音按停顿切回一句一段，给出句界（两遍预测，歧义处带警告）
  - `prep_audio.py` —— 配音后期：压句间停顿、产出时间表、整句字幕、配乐混音
  - `record.mjs` —— 把 anatomy 生成的会动的网页录成逐帧图片序列（CDP 抓帧）
  - `assemble.py` —— 按时间顺序拼分段视频、烧字幕、混音轨，出成片

**为什么核心代码不多？** 因为重的活不自己造轮子：解剖图由开源 skill [anatomy](https://github.com/wheresryan22/anatomy) 生成，配音调 Gemini API，编码用 ffmpeg。这个仓库负责把它们按正确的顺序和标准串起来——know-how 在说明书里，代码只补缺口。

## 先说清：谁能复刻、要什么条件

这套流程的定位是"**不会写代码的人，指挥一个会写代码的 AI 助手来做**"。复刻前请先对一下条件，缺哪样都跑不通：

- **一个能跑代码的 AI 助手环境**（如 Muse、Muse 等支持 skill 的工具，多数是订阅制）。本仓库不是双击就能用的软件，纯手动照着做不现实。
- **Gemini API key**（配音用）：在 Google AI Studio 申请。注意 Gemini API 有**地区限制**，部分地区直连不通，需要自备可达的网络条件；免费额度按生成次数限流，产量大要开付费（按量计费，不贵）。
- **anatomy skill**：开源免费，装到助手环境里（地址见下）。
- **本机基础工具**：node、python3、ffmpeg——都由 AI 助手代为调用和检查，你不需要会用。
- **素材**：Mixkit 免费授权，免登录下载。

条件都齐，照着 `SKILL.md` 七步走就能复刻出同类片子；案例的脚本、时间表、图规格都在 `examples/` 里，可以对照着验。

## 七步流程（顺序不要乱）

1. **定题 + 核事实** —— 找一句话能说清的矛盾；每个数字先核出处，通稿与独立来源交叉
2. **脚本** —— 先算字数（中文解说 5–6 字/秒）再写稿，一句一个信息点
3. **配音** —— Gemini TTS 全文一次生成 → 切句得到时间表（镜头长度由配音决定，所以配音在画面之前）
4. **画面** —— anatomy 生成解剖图网页，一图一知识点，录屏取动画
5. **素材** —— Mixkit 实拍 + 真实授权配乐（禁用 AI 合成音乐）
6. **合成** —— 按时间表拼装，切换卡在标点上，字幕整句上屏
7. **交片自检** —— 逐句抽帧核对画面↔解说↔字幕，全片听一遍，不过不交付

配套的公众号教程文章排版规则也收在 `SKILL.md` 文末。

## 快速开始

**前置条件**

- 一个能读写文件、能跑命令的 AI 助手环境（如 Muse / Muse 等支持 skill 的环境）
- **Gemini API key**（配音用；免费额度按生成次数限流，量大需开付费）
- 已安装 anatomy skill：`github.com/wheresryan22/anatomy`
- 本机有 node、python3、ffmpeg，能访问 Mixkit

**安装**：把本仓库克隆或下载到你的助手 skill 目录，保持 `SKILL.md` 与 `scripts/` 的相对位置不变。

**用法**：对助手说「按 explainer-video-pipeline 做一条科普视频，主题是 XX」，助手会按七步执行；开工前它会先确认 Gemini key 等前置条件，缺了会停下来问你。

## 已知局限（先说清）

- 切句的时间表是"预测 + 人工复核"制：个别句界会歧义，脚本会在 `warnings` 里点名候选停顿，流程的第 3、7 步有复核环节兜底。
- anatomy 只能出会动的网页（另可出 PNG / PDF），**没有视频导出**，视频化靠本仓库的录屏脚本。
- 讲结构的片子不要用 AI 生视频（标注会画坏、结构会漂、动作时序不可控）——这是流程的明确取舍，氛围镜头用实拍素材顶。
- 配音额度与价格以 Google 当期政策为准。
